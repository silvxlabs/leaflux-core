# LeafLux Documentation

## About
LeafLux is an API that computes relative irradiance for a given canopy and
optionally, terrain. The goal of LeafLux is to provide irradiance information
at much finer resolution than is usually provided. We use Beer's law to
calcualte the attenuation of light through a canopy and are able to provide
relative irradiance values for 1m^2 voxels on the surface, either on terrain
or a flat surface.
